# 📦 Blinkit Data Analysis Project

This project showcases a comprehensive analysis of Blinkit-like grocery delivery operations using a **dummy dataset** stored in a relational SQL database. It covers schema design, SQL-driven insights, and an interactive Power BI dashboard.

## 🔧 Tools Used
- **MySQL** – Database creation and SQL querying
- **Power BI** – Dashboard and visualization
- **SQL** – For data analysis

## 📁 Files Included
- `create.sql` – SQL script to create tables and relationships
- `analysis.sql` – SQL queries for analyzing data
- `dashboard.pbix` – Power BI file containing the interactive dashboard

## 📊 Key Dashboard Insights
- **600+ orders** from **500 users**, generating over **3M revenue**
- **Top categories**: Food, Electronics, Fashion, Books
- **Best-selling products**: Biba Dress, Levi’s Jeans, iPhone
- **Delivery analysis**: Only **23% on-time**, with avg delay of **123 mins**
- Visuals: Sales & revenue trends, category-wise breakdown, delivery performance

## 🚀 How to Run
1. Execute `create.sql` in MySQL to set up the database.
2. Run queries from `analysis.sql` to explore the data.
3. Open `Blinkit_Dashboard.pbix` in Power BI to view insights.
